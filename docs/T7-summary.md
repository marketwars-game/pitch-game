realtime layer — เปลี่ยนเฉพาะเนื้อหา, โจทย์, เกณฑ์กรรมการ, และ UI ทั้ง 3 ฝั่ง

## 5. บทเรียนเทคนิค (ต้องจำ)

1. **FitStage ห้ามใช้ `grid place-items-center`** — grid ไม่จัดกลางเมื่อกล่องลูก
   (1920×1080) ใหญ่กว่ากล่องแม่ (จอจริง) ภาพจะเลื่อนไปมุมขวาล่าง
   ต้องใช้ `position:absolute; left:50%; top:50%; transform:translate(-50%,-50%) scale(s)`
   โดย s = min(w/1920, h/1080) — **fit-to-screen บนโปรเจกเตอร์จริงผ่าน**
2. **ตัวอักษรไทย >60px ต้อง `line-height ≥ 1.25`** และ **ห้าม `background-clip:text`**
   (วรรณยุกต์หาย) — แสงกวาดใช้เลเยอร์ตัวอักษรซ้อน + mask แทน
3. **ห้าม `vh/vw` ข้างในผืนผ้าใบ** — อ้างอิงจอจริงไม่ใช่ผืนผ้าใบ
   (แก้ keyframe confetti 110vh → px)
4. **Tool Use หลาย persona ที่ต้องการ output ต่างกัน = ต้องแยก schema จริง** —
   optional field + คำอธิบาย "เฉพาะ X" ไม่พอกัน Haiku เลือกช่องผิด
   (นี่คือ hotfix 1 และพิสูจน์แล้วว่าจำเป็นจริงที่สเกล 63 คน)
5. **ค่า config ใน DB (jsonb) ชนะ DEFAULT ในโค้ดเสมอ** — เปลี่ยนเวลาเขียนต้อง
   รัน SQL ไม่ใช่แก้โค้ด
6. **เกณฑ์ AI ที่วัด "ความรู้สึก" ต้องมีเพดานตัวเลขที่นับได้กำกับ** — เกณฑ์
   เชิงคุณภาพล้วน (พี่เก่ง = "กล้าขึ้นไหม") ปล่อยให้คำตอบ generic สวยๆ ผ่านได้
   ต้องใส่กฎนับได้ (GENERIC_CAP) มาบังคับ ไม่งั้นคำตอบไม่ตรงเคสลอยขึ้นบน
7. **การจูน prompt กรรมการควรกันไฟล์เดียว** — ทั้ง hotfix สูตรและ v5-v7 แก้แค่
   `judge-prompts.ts` (v7 ยังมี anthropic.ts จาก hotfix 1) ทำให้จูนหน้างานได้เร็ว
   ปลอดภัย ไม่กระทบส่วนอื่น
